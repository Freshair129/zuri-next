# NFR-016-001 — Dragging movements have equivalents

Every drag interaction SHALL have a single-pointer, keyboard-reachable equivalent (WCAG 2.2 SC 2.5.7, NFR-008). Measured by browser accessibility tests shipped with each gesture.
