# Decisions — Marketing

No domain-specific ADR is assigned to Marketing in this pass. The Marketing lane's
design authority in the legacy repository is the owner-approved
`docs/change-requests/CR-018-MARKETING-DOMAIN-DESIGN.md` change request (not an ADR),
referenced from `docs/domains/marketing/CHARTER.md`; it is not converted to an
`ADR-MKT-*` entry here because it was never declared as an ADR in the legacy system,
and no ADR outside this pass's other assigned domains (ADR-076/066/074/083/084/098/
055/056/057/059/038/108) was found to govern Marketing specifically.

If a future pass finds a Marketing-specific ADR, it is added here with the next free ADR number
with the same Status/Context/Decision/Consequences/Legacy shape used elsewhere in
this blueprint.
