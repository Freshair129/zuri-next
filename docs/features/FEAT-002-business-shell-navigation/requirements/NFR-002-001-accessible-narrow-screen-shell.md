# NFR-002-001 — Accessible, narrow-screen shell

The shell SHALL meet WCAG 2.2 AA (named landmarks, one current module/view marked, keyboard-operable disclosures with focus return) and remain usable at 375–390 px without horizontal scroll (NFR-003, NFR-008). Measured by the navigation browser suite at desktop and 390 px.
