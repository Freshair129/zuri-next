# NFR-006-001 — Views usable at desktop and narrow widths

Graph and grid views SHALL remain usable at 1280 px and 390 px (pan/scroll, no clipping) and meet WCAG 2.2 AA; colour never carries meaning alone (NFR-008). Measured by the Project Work browser suite.
